# 📖 ReadWell
### *Read freely. Write boldly.*

ReadWell is a free, open library platform for readers and writers. It gives emerging writers and researchers a space to reach real audiences, and gives readers a home for free fiction and non-fiction content — all in one place.

---

## ✨ Features

### For Readers
- Browse free fiction & non-fiction across all genres
- Reading comfort settings — font size, dark/sepia/light mode
- Reading progress tracking per book
- Like, bookmark, follow authors, comment, and message writers
- ☕ Tip authors at the end of each chapter (min. $2)
- Seasonal themes that change automatically 🌸☀️🍂❄️

### For Writers — WriteWell Extension
- Built-in rich text editor with formatting tools
- Publish standalone works, series, or multi-book collections
- Set age ratings (G, PG, PG-13, 18+) and genres
- Schedule chapter releases
- Auto-save drafts so you never lose your work
- Writer dashboard — track reads, followers, and tips earned

### Platform
- ⭐ Starred/Featured works section (trending or paid placement)
- Writing prompts community
- Genre categories & search
- Admin panel with full platform control
- Moderator panel for content review and reports
- 90% of tips go directly to writers · 10% supports the platform

## 📱 PWA — Install on Your Phone

ReadWell is a **Progressive Web App (PWA)**. No app store needed!

1. Open the site in your mobile browser
2. Tap the browser menu
3. Tap **"Add to Home Screen"**
4. Done — it installs like a real app with an icon! ✅

---

## 🚀 Deploying on GitHub Pages (Free)

1. Create a GitHub account at [github.com](https://github.com)
2. Create a new **public** repository named `readwell`
3. Upload these files:
   - `index.html`
   - `manifest.json`
   - `sw.js`
4. Go to **Settings → Pages**
5. Set source to **main branch** → Save
6. Your app will be live at:
   `https://yourusername.github.io/readwell`

## 🎨 Color Schemes

ReadWell ships with 3 built-in themes plus seasonal auto-theming:

| Theme | Colors |
|-------|--------|
| Default | Dark Blue · Teal · Ashen White |
| Spring 🌸 | Deep Green · Soft Green |
| Summer ☀️ | Navy · Sky Blue · Yellow |
| Autumn 🍂 | Dark Brown · Burnt Orange |
| Winter ❄️ | Deep Navy · Ice Blue · Silver |

Season themes switch automatically by calendar month. Admin can override manually.

## 💰 Tip System

- Readers tip writers a minimum of **$2**
- **90%** goes directly to the writer's PayPal
- **10%** goes to the platform (visible only to Admin)
- Guest tipping supported — no account required to tip
